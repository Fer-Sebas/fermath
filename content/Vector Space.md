# Overview
A vector space is an [algebraic structure](Algebraic%20Structures) defined as a set of [vectors](Vector%20Space.md#Vector) $V$ where vector addition ($u + v \in V$) and scalar multiplication 
($\lambda v \in V, for \lambda \in \mathbb{F}$) satisfy the following rules.

# Axioms 
A vector space is always defined over a [[Field]] $\mathbb{F}$. For all vectors $u,v,w \in V$ and scalars $a,b \in \mathbb{F}$:
## Addition
Is commutative: $u+v=v+u$. 
Is associative: $(u+v)+w=u+(v+w)$. 
Has an identity element: there exists $0 \in V : \space v+0=v$. 
Has inverses: each $v$ has a unique −$v$ such that $v+(−v)=0
## Scalar Multiplication
Is associative: $(ab)v=a(bv)$
Has an identity element: $1v=v$
Is distributive: 
		$a(u+v)=au+av$
		$(a+b)v=av+bv$

# Vector
A vector is an element of a vector space. A vector is anything that behaves like a displacement under addition and scaling
