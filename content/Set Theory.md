# Sets
A set ($S$) is any collection of definite, distinguishable objects of our intuition or of our intellect to be conceived as a whole.

The objects are called **elements** or **members**. **Membership** is a relation between objects and sets. 

A set its regarded as a single entity.

# Principles
## Extension

> _Two sets are equal if (and only if) they have the same members._

The equality of two sets $X$ and $Y$ will be noted as $X=Y$ and the inequality as $X \not = B$.

## Abstraction

> _Every property determines a set._

$\{ x|P(x) \}$: The set of all $x$ such that property $P(x)$ holds.
