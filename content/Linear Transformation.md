# Overview
A linear transformation is a function that takes a vector as input and produces another vector in the same or a different [vector space](Vector%20Space.md). 

$$\huge T: V \mapsto W $$

It is defined purely by how it maps vectors, not by distances or geometric shapes. 

A linear transformation may stretch, rotate, reflect or shear space, but it must preserve vector addition and scalar multiplication. 

Straight lines through the origin remain straight and the origin stays fixed.
# Classification
## Linear Operator
A linear operator is defined as a linear transformation from a vector space to itself.
## Linear Map
A linear map can be used to indicate that the linear transformation is from a vector space to another.
