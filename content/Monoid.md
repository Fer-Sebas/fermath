# Overview
 A monoid is an [algebraic structure](Algebraic%20Structures) consisting of a set equipped with an [[identity]], along a [closed](closure) and [associative](associativity) binary operation.
  $$\huge(S, \space *, \space e)$$

A monoid in which ever element admits an inverse forms a [[group]].
