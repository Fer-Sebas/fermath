# Overview
Identity is an [algebraic property](Algebraic%20Properties) of a set relative to an operation. It states that given a set and a binary operation, there exist an element that leaves every element of the set unchanged when combined with it.

# Definition
Given a set $\large S$ and a binary operation $\large \circ$, there is an element $\large e \in S$ such that for all $\large s \in S$:
<br><br>$$ \large e \circ s = s \space \space and \space \space s \circ e = s$$<br><br>
## Uniqueness of identity
If an identity element exists for a binary operation on S, then it is unique.
