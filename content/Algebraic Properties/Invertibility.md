# Overview
**Invertibility** is an [algebraic property](Algebraic%20Properties.md) of an element relative to a binary operation. It states that an element can be undone by another element under that operation, yielding the [identity element](Identity).

Let $\large (S, \circ)$ be a set with a binary operation and an identity $\large e$.

An element $\large a \in S$ is invertible if there exist $\large b \in S$ such that:
<br><br>$$\Large  a\circ b = e \space \space and \space \space b \circ a= e $$<br><br>
The element $\large b$ is called an inverse of $\large a$, and is written as $\large a^{-1}$.

The property is not the *undoing* element itself, but **the fact that such an undoing element exists**.
