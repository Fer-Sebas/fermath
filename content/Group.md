# Overview
A group is an [algebraic structure](Algebraic%20Structures.md) consisting of a set equipped and a binary operation that is [associative](associativity) and [closed](closure), has an [[identity]] element and for which every element admits an [[inverse]].

A group whose binary operation is commutative is called an [[abelian group]].
