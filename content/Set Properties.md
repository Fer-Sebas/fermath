# Cardinality
The number of elements in a [set](Set%20Theory.md) *a.k.a.* its size, is called **cardinality**. It is noted using the set letter ($\large A$) between two pipes ($\large |A|$). 

Lets say that $\large A=\{a,b,c,d,e,f \}$ thus $\large |A| = 5$
## Counting
Counting is the process of determining the cardinality of a set. Counting corresponds to assigning a natural number to represent the number of distinct elements.

We can define a counting function as:
$$ \Large f(X) = |X|$$
### Countable Sets
A set is **countable** if its elements can be put into a **bijection** with the natural numbers $\large \mathbb{N}$. This includes all finite sets ($\large\{1,2,3\}$) and some infinite sets, like $\large \mathbb{N}$ itself, $\large \mathbb{Z}$, and $\large \mathbb{Q}$.
### Uncountable Sets
A set is **uncountable** if no such correspondence with $\large \mathbb{N}$ exists. For example the set of real numbers $\large \mathbb{R}$ is uncountable, as shown by Cantor's diagonal argument. This proves that $\large \mathbb{R}$ has a strictly larger cardinality than $\large \mathbb{N}$.
