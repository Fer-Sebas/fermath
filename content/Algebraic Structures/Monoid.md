# Overview
 A monoid is an [algebraic structure](Algebraic%20Structures.md) consisting of a set equipped with an [[Identity]], along a [closed](Closure.md) and [associative](Associativity.md) binary operation.
  $$\huge(S, \space *, \space e)$$

A monoid in which ever element admits an inverse forms a [[Group]].
