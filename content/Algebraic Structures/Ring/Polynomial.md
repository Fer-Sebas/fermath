# Overview
A polynomial over a [ring](Ring) $\large R$ is an algebraic object consisting of a finite sequence of coefficients of a variable multiplied by coefficients, for which there is only one coefficient per power such that $(a_0 + a_1X + a_2X^2 + ... + a_nX^n)$
