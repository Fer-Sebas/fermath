# Overview
A basis is a set of [linearly independent](Linear%20Independence.md) vectors that [spans](Span.md) the [space](Vector%20Space.md).
# Basis Vector
A **basis vector** is one of the [vectors](Vector%20Space.md#Vector) in a chosen set that forms a **basis**. As a result, every vector in the space can be written **uniquely** as a [[Linear Combination]] of these vectors. 

The number of basis vectors equals the dimension of the space, and whether a vector is a “basis vector” depends entirely on the chosen basis—there is nothing intrinsic about a specific vector being a basis vector outside that context.
