# Overview
A group is an [algebraic structure](Algebraic%20Structures.md) consisting of a set equipped and a binary operation that is [associative](Associativity.md) and [closed](Closure.md), has an [[Identity]] element and for which every element admits an [[Invertibility]].

A group whose binary operation is commutative is called an [[abelian group]].
